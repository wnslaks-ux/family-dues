# 가족 회비 현황 (family-dues)

카카오뱅크 모임통장 등으로 매달 내는 가족 회비를 **누가 냈는지/안 냈는지** 확인하고, 미납자에게 보낼 **카카오톡 문구를 복사**하는 웹앱입니다.
Spring Boot 2.7 + JSP + MyBatis + H2 (충남 입찰통계와 같은 구조/디자인).

## 실행
```
mvn spring-boot:run      # http://localhost:8080
```
- 홈 `/`, 이번달현황 `/dues?ym=2026-10`, 멤버관리 `/members`, 회비설정 `/settings`, 로그인 `/login`
- 기본 관리자: `admin` / `admin123` (환경변수 `ADMIN_USERNAME`, `ADMIN_PASSWORD`로 변경)
- 누구나 현황은 볼 수 있고, 완납 체크·멤버·설정 수정은 관리자만 가능

## 설정 바꾸기
- 멤버: `/members`에서 추가·수정·비활성·삭제 (초기값: 김지애, 김지은, 김지영, 김지원)
- 금액·납부일·모임 이름·계좌 문구·카톡 템플릿: `/settings` (초기 금액 0원 → 직접 입력)
- 달을 처음 열면 활성 멤버 전원이 그 달 금액으로 '미납' 생성됩니다.
- 데이터는 `./data/familydues.mv.db`에 저장됩니다.

## 카카오톡 관련
카카오 송금 내역 자동 확인·카톡 자동 발송은 **지원하지 않습니다** (개인용 API 없음). 모임통장 앱에서 입금 확인 후 직접 체크하고, '카톡문구 복사' 버튼으로 복사해 카톡에 붙여넣으세요.

## 배포
`Dockerfile`, `render.yaml` 포함. Render 무료 플랜은 디스크가 없어 재시작 시 H2 데이터가 초기화될 수 있습니다(유료 디스크 또는 외부 DB 권장).
